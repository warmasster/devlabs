M6 · Self-host en un comando

Criterio: de cero a primer lab en menos de 10 minutos, sin tocar configuración.

Prueba real

Aún no se ha medido.

Linux

Ubuntu/Debian con systemd. Las microVMs necesitan KVM.

sudo bash instalador/install.sh

Con release publicada: curl -fsSL …/install.sh | sudo sh

Windows 10/11

Crea su propia distro WSL2 «relavops» y no toca las tuyas. Las microVMs funcionan gracias a la virtualización anidada de WSL2 en Windows 11.

powershell -ExecutionPolicy Bypass -File instalador\install.ps1

Se quita con wsl --unregister relavops.

Mac

VM Linux con Lima (vz + virtiofs). MicroVMs solo en M3 o posterior con macOS 15+. Sin probar todavía.

brew install lima
limactl start --name relavops instalador/lima-relavops.yaml

Por qué no basta un docker compose up

Sysbox, Containerlab y Firecracker se instalan en el host (runtime de Docker, red y KVM), algo que un compose no puede hacer. Por eso el instalador es un script, y el mismo install.sh sirve para Linux, para WSL y para Lima.
